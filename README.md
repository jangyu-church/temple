# 솔로몬 성전 산책

열왕기상 6–8장과 역대하 3–4장을 바탕으로 솔로몬 성전의 공간과 의미를 3D로 걸어 보는 교육용 복원 모형입니다.

- 바로 보기: https://jangyu-church.github.io/temple/
- 본문에 기록된 치수를 기준으로 하고, 기록이 없는 부분은 화면에 ‘복원 가정’으로 표시했습니다.

![미리보기](preview.png)

## 앱으로 받기
휴대폰에서 주소를 열고 위쪽의 **앱으로 받기** 단추를 누르면, 기기에 맞는 설치 방법이 나옵니다. 한 번 설치해 두면 인터넷이 약한 곳에서도 열립니다.

- 아이폰: 사파리 → 공유 → 홈 화면에 추가
- 안드로이드: 크롬 → ⋮ → 홈 화면에 추가(앱 설치)

3D 표시에는 [three.js](https://threejs.org) (MIT 라이선스, `vendor/LICENSE-three.txt`)를 사용합니다.
